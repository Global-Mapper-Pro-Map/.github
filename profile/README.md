## Four Beats

1. **Name the map.** Give the Global Mapper Pro session a short title before you stack imagery or vectors.
2. **Pin the live layers.** Keep current raster layers and the vector overlay on the Global Mapper Pro board and leave unused coverages aside.
3. **Check the terrain.** Read the Global Mapper Pro summary of terrain analysis before you treat an elevation view as final.
4. **Close the loop.** Note which layers are ready so the next Global Mapper Pro visit does not start by hunting the map workspace.

No. Global Mapper Pro sits beside the imagery, vectors, and elevation files you already use.

## Field Note

Global Mapper Pro is easier to trust when the map stays smaller than the folder it came from. A named session shows which review is active, the pins show which raster layers you will stack today, and the closing note tells the next person which terrain analysis drives the vector overlay. That record is short on purpose: not a copy of every coverage, only the path back to the map workspace that is still open.

The same loop fits a student GIS desk, a client imagery packet, or a computer shared by two mappers. Open the last Global Mapper Pro session, confirm one elevation view, and leave the vector overlay easier to follow than you found it. Printed sheets stay where they are. Global Mapper Pro only holds the raster layers, the map workspace, and the handoff.

## One Real Pass

Pick a map that already has a name: a short ortho tile, a contour patch, or a thin vector corridor. Open it in Global Mapper Pro, keep only those layers on the board, and read one terrain surface you can point to. A pass is done when that surface stays tied to the raster layers and the unused coverages are no longer in the way. Global Mapper Pro does not need a full rebuild of the map workspace before it is useful.

If the pass feels crowded, the stack is too wide. Drop anything that belongs to a different map and leave it out of this workspace. The next pass can have its own title. What matters is that this one stays readable from the first raster to the last overlay, with the summary still matching the terrain analysis on the board.
